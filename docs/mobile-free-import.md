# 手机免费导入运动和睡眠

最快开始的方法是使用现有健康日志的 **Apple 健康 XML 手动导入**。不需要另外购买同步 App，也不需要先租服务器或运行 GitHub 中的 Python 后端。

## 手机操作

1. 打开 iPhone「健康」App，进入头像页面，选择「导出所有健康数据」，保存到「文件」。
2. 打开「文件」App，轻点导出的 ZIP 解压，找到 `export.xml`。
3. 用 Safari 打开[健康日志](https://adi-health-journal.qidisong.chatgpt.site)，登录同一个账号。
4. 选择「聊天与数据」，在「Apple 健康」中选择解压后的 **export.xml**。选择后会立即开始导入，等待完成提示。
5. 核对一晚睡眠和一条运动记录。然后在手机 ChatGPT 选择「阿迪的健康日志」，发送：「读取最近七天的运动和睡眠记录。」

选择的是 XML，不是 ZIP 或 `export_cda.xml`。原始文件在浏览器中解析，接口只接收提取后的运动、睡眠与体重记录；不用把完整健康导出文件发送到聊天。

这是手动导入。以后有新数据，需要再次导出、导入；尚未开启后台自动同步。重复标识会更新对应记录，修正后的导入也会核对并清理同一文件在旧版解析中产生的、仍精确匹配的错误睡眠日期片段。手工记录、其他账号或内容已经变化的记录不会被这项清理删除。

## 保存在哪里

手机插件和现有网页共用该 Site 的 Cloudflare D1 数据库，记录按已认证的用户保存。新聊天可以重新通过插件查询。

仓库中的 `sites/health-journal/` 是这个网页及插件的源码；根目录的 FastAPI/PostgreSQL 是另一套独立后端。两者目前不自动互通，向独立后端发送数据不会自动出现在现有手机插件中。

## 导入范围

- 运动：导出文件里的训练项目及开始到结束的时长；该时长可能包含暂停，不等同于活动圆环的锻炼分钟。
- 睡眠：识别已知睡眠阶段，合并重叠时间，卧床和清醒不计入实际睡眠时长。同来源、同设备相连的阶段按最终睡眠结束日归属。没有连接依据的片段保持独立，不猜测长时间空白属于同一晚。
- 体重：转换为 kg 后保存。

当前保存结构化汇总，不保存原始完整健康档案、睡眠分期曲线或训练 GPS 路线。导出或解析大文件的速度取决于设备和历史数据量；首次导入后应与 Apple 健康核对。网页周报、月报默认展示近期数据，早期导入的记录不一定出现在这些视图中。

## 后续需要减少手动操作时

可以再配置免费的原生快捷指令做每日汇总，但设备授权、可靠的睡眠区间合并、受保护上传和后台运行都需要额外设置。当前版本不会把文件导入描述为实时自动同步。

Apple 官方操作：[导出健康数据](https://support.apple.com/zh-cn/guide/iphone/iph5ede58c3d/27/ios/27)、[在 iPhone 解压 ZIP](https://support.apple.com/zh-cn/102532)。
