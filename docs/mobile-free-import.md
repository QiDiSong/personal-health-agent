# 每月导出一次，在手机或电脑回看健康记录

完整步骤已更新到[月度健康使用指南](../sites/health-journal/docs/monthly-health.md)。

1. iPhone「健康」→ 头像 →「导出所有健康数据」→ 保存 ZIP 到「文件」。
2. Safari 登录[健康日志](https://adi-health-journal.qidisong.chatgpt.site)，点「导入每月健康文件」，直接选择 ZIP，等待完成。无需先解压；也支持 `export.xml`。
3. 回到「月度健康」看最近30天或选择历史月份。重复导入更新对应记录，旧月份继续保存。
4. 食物未写入苹果健康时，点「＋ 补充记录」填写日期、食物与份量，或在 ChatGPT「阿迪的健康日志」中记录。

不需要搭快捷指令、付费同步 App、Mac 或先运行 Python 后端。原始 ZIP/XML 留在浏览器，仅结构化记录上传到现有站点的私有 D1 数据库；手机网页与插件共用，GitHub 不保存健康文件或访问密钥。单文件200MiB、XML150MiB限制和统计来源规则见完整指南。尚未代用户在真实 iPhone 导出文件上验证；首次核对实际睡眠、训练与一天步数。

Apple 官方操作：[导出健康数据](https://support.apple.com/zh-cn/guide/iphone/iph5ede58c3d/27/ios/27)。
