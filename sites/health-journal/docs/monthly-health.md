# 每月一次：手机导出，网页保存和回看

网页：https://adi-health-journal.qidisong.chatgpt.site/

## 每月只做这几步

1. iPhone 打开「健康」→ 右上角头像 →「导出所有健康数据」。
2. 导出完成后，点分享 →「存储到文件」，保存 ZIP。苹果导出的是全部历史，不能在此步骤只选某个月。
3. 用 Safari 打开上面的网页并登录，点「导入每月健康文件」或「聊天与数据」，选择刚才的 ZIP。**无需解压，也无需快捷指令或额外 App。**
4. 等待完成提示，回到「月度健康」，查看「最近 30 天」，或选中一个具体月份。电脑和手机 ChatGPT 插件读取同一份已保存记录。

重复导入相同文件会更新相同标识的记录，不会每次累计一份。网页保留以前导入的历史月份；更换聊天或电脑也可以重新读取。手机端删除的数据不会自动删除网页旧记录，需要在网页或聊天中明确删除。

## 可以看到什么

| 方面 | 已支持的记录 |
| --- | --- |
| 饮食 | 已写入健康的热量、蛋白质、脂肪、碳水、膳食纤维、糖、钠、饮水，以及网页／ChatGPT 手动补记的食物与份量 |
| 睡眠 | 睡眠时长趋势、入睡／起床时间、有记录日平均；合并重叠阶段，清醒和卧床不算睡着 |
| 运动 | 具体训练项目、次数、训练时长；Apple 圆环锻炼分钟单列 |
| 日常活动 | 步数、活动／静息能量、步行跑步距离 |
| 体重与身体指标 | 体重、BMI、体脂、心率、静息心率、HRV、血氧、呼吸频率（文件中有才显示） |

Apple Watch 不会自动知道你吃了什么。如果健康 App 没有饮食记录，在网页点「＋ 补充记录」选「饮食」，填写日期、食物和份量；也可以在手机 ChatGPT 的「阿迪的健康日志」中说“记录今天午餐……”。估算营养要标为估算，未知数值可不填。月底才想起补记时，请根据实际记录补充，不要猜整个月的餐食。

同一天同一营养指标有 Apple 健康汇总时优先用它，缺失项再用手动饮食的合计；两者不会重复相加。步数等累计指标按来源分别汇总，选择单个来源的最大日总量，不把 Watch 与 iPhone 相加。体征按有效样本最多的单一来源取平均。这是导出文件摘要，可能与健康 App 的来源优先级算法不同。缺失日期显示未知，不补成 0。

## 文件和保存

ZIP/XML 在浏览器中解压、解析，只上传支持指标的结构化记录。原始 ZIP、XML、训练路线和完整健康档案不上传。网页记录保存在现有站点的私有云端数据库中，与本次聊天会话分开；GitHub 只保存程序源码。

单文件最大 200 MiB，解压后的 XML 最大 150 MiB。过大的文件、ZIP64 或不支持的 ZIP，可先在自己的设备解压后选符合大小限制的 `export.xml`。不保证任意大小的健康历史都能在手机处理；解析期间保持网页打开。真实数据首次导入后，请与健康 App 核对一晚睡眠、一场运动和一天步数。

构建与合成测试不代替实际 iPhone 导出文件验证。没有该指标的传感器、没有授权或未写入健康的数据不会凭空出现。
